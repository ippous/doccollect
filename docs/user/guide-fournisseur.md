# Déposer vos documents

Un professionnel (notaire, comptable, agence…) vous demande des documents via DocCollect. Le dépôt est sécurisé : vos fichiers sont chiffrés et seul ce professionnel y a accès.

## 1. Créer votre accès (première fois)

1. Ouvrez le lien reçu par e-mail.
2. Choisissez un mot de passe (10 caractères minimum, avec majuscule, minuscule et chiffre).
3. Activez la **double authentification** : le plus simple est le **code par e-mail** ; si vous avez une application d'authentification sur votre téléphone, vous pouvez aussi l'utiliser.
4. Notez vos **codes de récupération** quelque part.

Les fois suivantes : connectez-vous avec votre e-mail, votre mot de passe et le code reçu.

## 2. Déposer les pièces

La page du dossier affiche la liste des pièces demandées, ce qui est déjà reçu et **ce qui manque**.

- **Choisir un fichier** : PDF ou image depuis votre ordinateur ou votre téléphone.
- **Prendre une photo** (sur téléphone) : photographiez directement le document, à plat et bien éclairé.
- Les formats et la taille maximale acceptés sont indiqués sous chaque pièce.
- Tant qu'un document n'a pas été transmis, vous pouvez le **retirer** pour le remplacer.

Si le professionnel refuse un document (illisible, périmé…), vous recevez un e-mail avec le motif : déposez-en un nouveau sur la même pièce.

Si une alerte indique que le document « ne semble pas correspondre », vérifiez que vous avez déposé la bonne pièce.

## 3. Ensuite

Selon le choix du professionnel, les documents lui sont transmis à chaque dépôt ou en une fois lorsque toutes les pièces obligatoires sont déposées. Vous recevez un rappel s'il manque encore des pièces.

## Sur téléphone

Depuis le navigateur, « Ajouter à l'écran d'accueil » installe DocCollect comme une application.

## Problème de connexion ?

- Mot de passe oublié : lien « Mot de passe oublié ? » sur la page de connexion.
- Plus d'accès à votre méthode de double authentification : utilisez un code de récupération, ou demandez au professionnel de contacter l'administrateur.
